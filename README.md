# AI 项目三 · 卸载大师

一个 Windows 上的软件卸载 + 残留彻底清理工具。单个 exe，双击就能跑，不用装任何运行库（只依赖系统自带的 .NET Framework 4.8）。

界面是深色的，卸载流程是"右键 → 直接进卸载 → 扫残留 → 勾选 → 选回收站还是永久删"，全程不超过 5 步。

## 功能

- **右键直接卸载**：在桌面或资源管理器里，对准软件的快捷方式 / exe / 安装文件夹点右键，选「用卸载大师卸载」，立刻进入卸载流程，不用先打开列表找软件。
- **识别已安装软件**：读取 HKLM、HKCU 各自的 32 位与 64 位卸载注册表，自动过滤系统补丁、更新包、驱动子组件。
- **调用软件自带卸载程序**：MSI 组件会把 `/I{GUID}` 改写成 `/X{GUID}`，直接走卸载而不是"修改"。
- **卸载后扫残留**：安装目录、Program Files / ProgramData / AppData 下同名目录、开始菜单和桌面的快捷方式、注册表项，全部列出来。
- **风险分级**：无风险 / 低风险的默认勾选，高风险（可能是公共目录、共享运行库、别的软件在用的）默认不勾，要用户自己确认。
- **两种删除方式**：移到回收站（可以还原）或永久删除（不进回收站，更快）。
- **安全兜底**：删注册表之前先 `reg export` 备份，备份失败就跳过不删；每次清理写一份日志。

## 用法

1. 运行 `卸载大师.exe`（会弹一次 UAC，必须点"是"，因为要删 Program Files 和注册表）。
2. 右键菜单：在桌面或文件夹里对软件图标点右键 → 「用卸载大师卸载」。
   Windows 11 一级右键菜单里可能看不到，点「显示更多选项」即可。
3. 双击 exe 也可以直接打开软件列表，在列表里选中软件点「卸载并彻底清理」。
4. 卸载完成后，会问要不要清残留 → 列出全部残留 → 选回收站或永久删 → 执行。

如果挪动了 exe 的位置，右键菜单会失效：打开程序，点底部「右键菜单」关掉再启用一次即可修好。

## 编译

不需要装 Visual Studio，用 Windows 自带的 .NET Framework 编译器：

```
重新编译.bat
```

它调用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，把 `src\*.cs` 编译成 `卸载大师.exe`，带清单（管理员权限 + DPI）和图标。

注意：这个编译器是 C# 5 语法，不能用字符串插值、`?.`、`out var` 这些新写法。

## 项目结构

```
src/                卸载大师源码（C# 5 / WinForms）
  Program.cs        入口，解析 /target 参数
  MainForm.cs       主界面 + 卸载流程 + 右键进来的流程
  ResidueForm.cs    残留清单窗口
  Forms.cs          等待窗、进度窗、删除方式选择窗
  ResidueScanner.cs 残留扫描与风险判定
  Cleaner.cs        删除（回收站/永久）、注册表备份、日志
  InstalledApps.cs  枚举已安装软件、解析卸载命令
  TargetResolver.cs 从右键目标反查是哪个软件
  ShellMenu.cs      注册/移除右键菜单
  Theme.cs          深色主题、自绘控件
src_test/
  TestProduct.cs    测试应用「测试产物」源码（带安装向导）
重新编译.bat       一键编译
使用说明.txt       中文使用说明
测试产物.exe       测试用安装包（装完故意留残留，用来验证清理）
卸载大师.exe       成品
```

## 测试用的「测试产物」

`测试产物.exe` 是个能真装真卸的小记事本，用来验证卸载大师：

- 双击进安装向导，可以选安装位置（默认 `%LocalAppData%\Programs\TestProduct`），不弹 UAC。
- 安装会写程序文件、桌面和开始菜单快捷方式、注册表安装信息、约 1 MB 数据。
- 它的卸载器**故意只删程序 exe 和安装记录**，把数据目录、缓存、快捷方式、注册表设置留着——正好让卸载大师去清。

## 注意

- 每次启动都会弹 UAC，必须点"是"。
- 别卸 VC++ 运行库、.NET、Edge / WebView2、输入法、显卡声卡网卡驱动，卸了别的软件会坏。
- 高风险项默认不勾，别乱勾。
