卸载大师 · 使用说明

一、最常用的用法：桌面右键直接卸载

1. 在桌面上（或任意文件夹里）对准要卸载的软件图标、exe 文件、或者它的安装文件夹，点右键。
2. 菜单里找到「用卸载大师卸载」，点它。
   Windows 11 小提示：一级右键菜单里可能看不到，点一下「显示更多选项」，在展开的菜单里就有。
3. 会弹出「是否卸载 XXX？」→ 点「是」。
   随后系统会弹一次「你要允许此应用对你的设备进行更改吗？」→ 必须点「是」。
   （不点的话程序没权限删除 Program Files 和注册表，清理会失败。）
4. 它自带的卸载程序会打开，你在里面按自己的步骤卸载（下一步 / 卸载 / 完成都行），
   卸载程序窗口关掉后，会回到「卸载进行中」小窗口，点「继续清理残留 →」。
5. 接着会扫描残留，然后弹窗问：找到 N 项残留，包括安装目录、缓存、空壳文件夹、
   开始菜单和桌面的快捷方式、注册表项 —— 要清理吗？
6. 点「是」后弹出完整清单：无风险和低风险的已经帮你勾好了，风险高的默认不勾，
   你想删就自己勾上。
7. 点「彻底清理」，最后再弹一个窗口问你：「移到回收站（以后能还原）」还是
   「永久删除（直接抹掉，找不回来）」，选好就开始删。

二、也可以双击直接打开

双击「卸载大师.exe」会打开软件列表（本机识别出 39 个软件）。
在列表里选中一个，点右下角「卸载并彻底清理」，后面流程和上面第 3 步开始完全一样。
右上角还有「扫描其它残留」，可以按软件名字去搜残留（适合已经手动卸载过的软件）。

三、安全相关

- 选「移到回收站」：文件进了回收站，之后还能右键还原。
- 选「永久删除」：不经过回收站，直接抹掉，不能恢复（大文件清理更快）。
- 注册表项在删除前会自动导出备份，位置：
  %APPDATA%\CleanUninstall\backup
- 每次清理都会写一份记录，位置：
  %APPDATA%\CleanUninstall\logs
- 程序底部有「清理记录 / 注册表备份」链接，点一下就能打开这些文件夹。

四、别乱卸这些

VC++ 运行库、.NET 运行库、Edge / WebView2、输入法、显卡声卡网卡驱动、Windows 自带组件。
卸掉这些东西，别的软件会打不开、没声音、上不了网。

五、关于右键菜单

- 现在是开启状态，菜单项名字叫「用卸载大师卸载」。
- 如果你把「卸载大师.exe」挪到别的文件夹，右键菜单会失效（它记的是完整路径）。
  打开程序，点底部「右键菜单：已启用」，先关掉再点一次「启用右键菜单」，就修好了。
- 不想用了，点底部那行字就能关掉右键菜单，不会在注册表里留东西。

六、源码

src 文件夹里是全部源码（C#）。双击「重新编译.bat」可以重新生成 卸载大师.exe，
不用装任何开发工具，用的是 Windows 自带的 .NET Framework 编译器。
